2 前端技术栈 FRONTEND
技术版本角色选型理由
Vue 3 3.5.x 核心框架 团队技术栈；Composition API 适合复杂表单（项目立项含货物明细多行）；RBAC场景有RuoYi-Vue3参考
TypeScript 5.5.x 类型安全 金额字段需要类型约束；接口参数类型定义；减少运行时错误
Vite 5.x 构建工具 团队技术栈；开发热更新快；生产构建体积小
Vue Router 4.x 路由管理 动态路由方案——登录后根据RBAC菜单权限生成路由表，参考RuoYi思路自实现
Pinia 2.x 状态管理 Vue 3标配；存储用户信息/权限/字典缓存；比Vuex轻量
Element Plus 2.8.x UI组件库 B端标准；表格/表单/树/对话框组件齐全；el-table支持复杂看板；表单校验完善
Axios 1.7.x HTTP客户端 拦截器统一处理JWT Token注入、401跳转登录、错误提示；~100个接口统一管理
ECharts 5.x 图表（V2预留） 看板图表（柱状图/饼图）V1不用，V2启用；按需引入控制体积
unplugin-auto-import 0.18.x 自动导入 Vue API + Element Plus组件自动导入，减少手动import
dayjs 1.11.x 日期处理 轻量；比moment.js体积小90%；日期筛选、审计日志时间格式化
decimal.js 10.x 金额计算 前端金额展示用decimal.js处理，避免浮点精度问题（后端为准，前端只展示）
@vueuse/core 11.x 组合式工具 useStorage持久化、useDebounceFn防抖搜索、useWindowSize响应式
RuoYi 借鉴点：① 动态菜单生成方案（后端返回菜单树→前端生成路由）② 字典组件思路（useDict composable按dictType加载并缓存到Pinia）③ RBAC管理页面交互模式。均参考思路自实现，不引入RuoYi代码。
3 后端技术栈 BACKEND
技术版本角色选型理由
Java 17 (LTS) 运行环境 Spring Boot 3 最低要求 Java 17；LTS版本稳定；Flowable 7 基于Java生态
Spring Boot 3.3.x 核心框架 Flowable原生集成Spring；生态成熟；自动配置减少样板代码
Flowable 7.x 审批引擎 业务模型v6.1已选定；支持驳回到任意节点、角色解析、自定义审批人；BPMN 2.0标准
MyBatis-Plus 3.5.x ORM框架 逻辑删除拦截器自动追加is_deleted=false；分页插件开箱即用；Lambda查询减少手写SQL
Spring Security 6.x 安全框架 JWT Token签发/校验；RBAC权限拦截器统一校验；方法级注解@PreAuthorize
Flyway 10.x 数据库迁移 DDL版本管理；种子数据初始化（角色/权限/菜单/字典）；和初始化安装向导配合
SpringDoc 2.x 接口文档 OpenAPI 3标准；~100个接口自动生成Swagger；和接口文档HTML对应
Hutool 5.8.x 工具库 日期处理、加密（密码加密）、Excel导出（V2）、验证码生成（重置确认）
Spring Scheduling 内置 定时任务 V1够用；清理超过30天的草稿、清理无引用临时文件、文件下载记录90天清理
Lombok 1.18.x 代码简化 @Data/@Builder/@Slf4j减少样板代码；26个实体大量DTO/VO受益
关键集成点： ① Spring Security + Flowable 共享用户体系，审批人通过 Spring Security 的 Authentication 解析 ② MyBatis-Plus 逻辑删除拦截器对26个实体统一生效，第二层实体自动过滤已删除数据 ③ Flyway 的种子数据脚本和 SysConfig 的 sys_initialized 标记配合，防止重复初始化
4 数据层 DATA
技术版本角色选型理由
MySQL 8.x 主数据库 Decimal(18,2)精确金额；InnoDB事务支持；行锁防并发核销；23张业务表+Flowable ACT_*表
Flyway 10.x 数据库迁移 已列后端，此处强调数据层职责：V1__init_schema.sql建表、V2__seed_data.sql种子数据
本地磁盘 — 文件存储（V1） 银行回单、发票文件存储；按 项目编号_类型_日期 命名；V1单机部署够用
MinIO —（V2预留） 对象存储（V2） V2容器化后切换；FileStorage接口抽象，切换不改业务代码
金额红线：所有金额字段必须使用 MySQL DECIMAL(18,2)，Java 端用 BigDecimal，前端用 decimal.js。三端统一，绝不允许 float / double。

6 DevOps & 部署 DEVOPS
技术版本角色选型理由
阿里云效 Codeup — 代码托管 私有仓库；代码审查；与云效流水线无缝集成；企业级权限管理
阿里云效 Flow — CI/CD 与Codeup原生集成；push触发自动构建→前端npm build→后端mvn package→部署；可视化流水线编排
Nginx 1.24.x 反向代理 前端静态资源托管；后端API代理转发；HTTPS终止
bin/ 脚本方案 start.sh / stop.sh / restart.sh 进程管理 fat JAR + java -jar；setsid守护化脱离终端；健康检查轮询60秒；防重复启动+端口占用预检；优雅停机SIGTERM→SIGKILL；比PM2更轻量，不装Node.js
.env/ 凭据管理 — 密钥隔离 .env/{profile}.env 不入库；example.env 入库模板；application-{profile}.properties 只写占位符；云效流水线注入私密变量

Docker —（V2预留） 容器化（V2） V1裸机部署够用；V2容器化提升部署一致性和扩展性
SpringDoc Swagger 2.x 接口调试 开发期间~100个接口在线调试；和接口文档HTML对应

7 协议与规范 PROTOCOL
规范约定说明
通信协议 HTTPS（TLS 1.2+） 财务系统必须加密传输
数据格式 application/json; charset=UTF-8 统一JSON，不混用XML
认证方式 Authorization: Bearer {JWT} 登录返回Token，每次请求Header携带
分页约定 ?page=1&size=20 返回 { list, total, page, size }
统一响应 { code, msg, data } code=200成功，非200失败；data为业务数据
错误码 200=成功 | 4xx=客户端错误 | 5xx=服务端错误 200成功 | 401未登录 | 403无权限 | 404不存在 | 409并发冲突 | 500服务器错误
金额传输 字符串类型（"10000.00"） JSON传输用字符串避免浮点精度丢失，后端BigDecimal接收
时间格式 ISO 8601: 2026-09-29T10:30:00+08:00 统一时区+08:00（北京时间）
文件上传 multipart/form-data 限制单文件≤10MB；允许.pdf/.jpg/.png/.xlsx
命名风格 前端 camelCase | 后端 snake_case MyBatis-Plus map-underscore-to-camel-case 自动转换
8 选型对比记录
决策点选方案弃方案理由
前端框架 Vue 3 React / Next.js RuoYi-Vue3可参考RBAC页面；Next.js偏C端/SSR场景用不上；团队Vue技术栈
后端框架 Spring Boot 3 NestJS Flowable 是 Java 生态，NestJS 无法集成；Spring + Flowable 原生整合
审批引擎 Flowable 7 Camunda / 手撕 业务模型v6.1已论证：全高复杂度审批需引擎；Flowable中文资料多、轻量
ORM MyBatis-Plus JPA / Hibernate 逻辑删除拦截器开箱即用；复杂SQL查询灵活；JPA对动态查询不友好
UI组件库 Element Plus Ant Design Vue Element Plus和Vue3生态更贴合；el-table复杂表格能力强；社区活跃
字典方案 双表（Type+Data） 单表+parent_id 对标RuoYi双表方案；按dict_type查询效率高；支持样式和默认值
项目架构 从零搭建 RuoYi 当底盘 用户要求借鉴参考不直接引入；避免RuoYi代码债；保持架构纯净
进程管理 bin/ 脚本方案 PM2 bin/start.sh + setsid守护化比PM2更轻量；不装Node.js；健康检查+防重复+优雅停机更可控
部署 裸机部署（V1） Docker（V1） V1单机够用；Docker留V2容器化时启用
